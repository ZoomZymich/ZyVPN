## ⚡ В чём фишка ZyVPN?

Большинство клиентов вроде *v2rayN* или *Nekoray* перегружены десятками непонятных меню, таблиц и параметров. **ZyVPN сделан для людей**:

* 🎯 **Вставил ссылку — нажал кнопку — всё работает**: поддерживаются как обычные ссылки (`vless://`, `vmess://`, `trojan://`, `ss://`, `hy2://`, `tuic://`), так и ссылки на подписки (Base64) и конфиги **Clash / Mihomo YAML**.
* ⚡ **Честная поддержка XHTTP (SplitHTTP) over TCP & Reality**: авто-определение транспортов, поддержка пакетного и стримингового режимов, отдельный фильтр `⚡ XHTTP` в списке серверов.
* 🇷🇺 **Умная авто-маршрутизация (Smart Bypass)**: российские ресурсы (Госуслуги, Сбер, Т-Банк, Яндекс, VK, Ozon, Кинопоиск, домены `.ru`, `.рф`, `.su`) и локальная сеть открываются напрямую без потери скорости. VPN включается только для заблокированных сервисов и зарубежных сайтов.
* 🌐 **Детектор IP и страны на лету**: при подключении сразу показывает реальный выходной IP-адрес, флаг и город сервера.
* 🔍 **Встроенный чекер сервисов с тестом Google Gemini**: проверка доступности Discord, YouTube, Telegram, Instagram, Twitter/X, Spotify, Wikipedia и глубокая проверка **Google Gemini** прямо в окне приложения.
* 🎨 **Удобный темный интерфейс**: Glassmorphism-дизайн, быстрый поиск серверов, пинг в миллисекундах и кастомное окно без громоздких рамок Windows.

## 🚀 Быстрый старт

### Способ 1. Готовый файл (рекомендуется)
1. Скачайте свежую версию из раздела [**Releases**](https://github.com/ZoomZymich/ZyVPN/releases).
2. Распакуйте архив в удобную папку (желательно без русских букв в пути).
3. Запустите **`ZyVPN.exe`** (или `ZyVPN.bat`).

### Способ 2. Запуск из исходного кода (Python)
Если хотите запустить или модифицировать проект самостоятельно:
```bash
# Клонируем репозиторий
git clone https://github.com/ZoomZymich/ZyVPN.git
cd ZyVPN

# Устанавливаем зависимости
pip install -r requirements.txt

# Запуск приложения
python run.py
```

## 📖 Как пользоваться

1. **Добавление сервера или подписки:**
   * Перейдите во вкладку **«Подписки»**.
   * Вставьте ссылку на подписку (Base64 / Clash YAML) или одиночный ключ `vless://...`.
   * Нажмите **«Добавить»** — серверы мгновенно появятся в списке.

2. **Выбор сервера и подключение:**
   * Во вкладке **«Серверы»** выберите нужный узел (можно отфильтровать по `⚡ XHTTP`, `Reality`, `VLESS` или найти по стране через поиск).
   * Вернитесь на главный экран и нажмите большую круглую кнопку **«Подключить»**.
   * Через пару секунд статус сменится на «Подключено», а плашка сверху покажет текущий IP и страну выхода.

3. **Проверка работоспособности:**
   * Перейдите во вкладку **«Проверка»** и нажмите **«Проверить все сервисы»**.
   * Приложение покажет статус и пинг до Discord, YouTube, Telegram и других ресурсов через текущий туннель.

## 🤖 Проверка сервисов и Google Gemini

Многие VPN-серверы открывают главную страницу Google Gemini, но при попытке отправить сообщение выдают ошибку:  
`"User location is not supported for the API use"`.

В ZyVPN встроен **трёхуровневый глубокий тест Gemini**:
1. **Веб-интерфейс (`/app`)**: проверяет вход без редиректов на `/unavailable`.
2. **Региональный фильтр генерации ответов Google AI**: опрашивает API генерации модели. Google проверяет геолокацию вызывающего IP **до** авторизации. Если сервер в разрешенной стране (Швеция, Австрия и др.) — допуск подтверждается.
3. **Шлюз чата RPC**: пингует внутренний канал сообщений (`alkalimakersuite-pa`).

> 💬 На карточке Google Gemini есть кнопка **«Тест диалога»**: вы можете написать произвольный вопрос и прямо в окне ZyVPN увидеть реальный ответ модели, подтверждающий 100% работоспособность переписки.

## 🔀 Маршрутизация

В настройках доступно два режима:

| Режим | Описание |
| :--- | :--- |
| **Обход РФ и LAN** *(Рекомендуется)* | Российские домены (`.ru`, `.рф`, `.su`), банки, Госуслуги и локальная сеть идут напрямую через вашего провайдера на максимальной скорости. Заблокированные ресурсы и зарубежные сайты идут через VPN. |
| **Global (Весь трафик)** | 100% всех сетевых запросов компьютера направляются через VPN сервер. |

Также поддерживается выбор безопасного DNS-сервера (Cloudflare `1.1.1.1`, Google `8.8.8.8`, Yandex `77.88.8.8`) для защиты от утечек (DNS Leak).

## ❓ Частые вопросы (FAQ)

<details>
<summary><b>Нужны ли права администратора для работы?</b></summary>
Для стандартного режима работы (системный прокси Windows) права администратора <b>не требуются</b>. Они нужны только если вы включаете виртуальный сетевой адаптер TUN (Wintun) для перехвата трафика отдельных игр или старых программ без поддержки прокси.
</details>

<details>
<summary><b>Что делать, если антивирус ругается на исполняемые файлы?</b></summary>
Все исполняемые бинарники ядра (<code>bin/xray.exe</code>, <code>bin/sing-box.exe</code>, <code>bin/wintun.dll</code>) скачиваются напрямую из официальных релизов соответствующих open-source проектов. Некоторые антивирусы реагируют на утилиты сетевого проксирования эвристикой. Проект полностью открыт, вы можете пересобрать бинарники самостоятельно или добавить папку в исключения.
</details>

<details>
<summary><b>Как собрать свой независимый EXE-файл?</b></summary>
В репозитории есть готовый скрипт сборщика:
<pre>python scripts/build_exe.py</pre>
Готовая сборка появится в папке <code>dist/release/ZyVPN/ZyVPN.exe</code>.
</details>

## 🛠️ Стек технологий

* **GUI / Фронтенд:** HTML5, CSS3 (Glassmorphism Dark Theme), Vanilla JavaScript.
* **Десктопная оболочка:** Python 3.12 + [pywebview](https://github.com/r0x0r/pywebview) (MS Edge WebView2 Runtime).
* **Сетевые ядра:** [Xray-core](https://github.com/XTLS/Xray-core) (VLESS, XHTTP, Reality) + [sing-box](https://github.com/SagerNet/sing-box) (Hysteria 2, TUIC, TUN).
* **Системная интеграция:** Windows WinINet API, Wintun.
